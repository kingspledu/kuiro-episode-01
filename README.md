# 귀로 — 1화. 폐쇄 완료 (현재형)

원작: @Andrew Cho

공개 독서 페이지: https://kingspledu.github.io/kuiro-episode-01/

원문 전체를 먼저 배포한 뒤 3×3 그리드에서 분리한 81개 웹툰 장면을 9개 배치로 순차 반영한 한국어 도시판타지 리더입니다. 상단 플로팅 목차, 14–50pt 글자 조절, 라이트·다크 테마, 설치형 전체화면 PWA를 포함합니다.

인물·배경 분석과 참조 시트: [제작 설정 페이지](https://kingspledu.github.io/kuiro-episode-01/production.html)

- `story.json`: 원문 블록과 읽기 구간. 구간 제목은 편집상 구분이며 본문 순서를 유지합니다.
- `character-bible.json`: 명명된 인물 4명과 관리인·언급 집단까지 분석한 모델/상태 설정. 원문 사실과 외형 제작 선택을 구분합니다.
- `environment-bible.json`: 10개 공간/상태의 배치, 조명, 소품과 동선.
- `scene-manifest.json`: 81씬의 원문 위치, 인물·배경 ID, 이미지 경로·실제 크기, 배포 기록.
- `image-prompts.json`, `reference-prompts.json`: 실제 생성 및 공간·자세 수정 프롬프트.
- `release-log.json`: 전체 SHA로 확인한 배치별 Pages 배포 결과.

내장 이미지 도구에는 해상도 지정 옵션이 없어 프롬프트로 최고 네이티브 해상도를 요청했습니다. 실제 반환 그리드는 1254×1254px, 분리 컷은 약 412×412px입니다. 원본 픽셀을 인위적으로 확대하지 않았습니다. 그림은 AI 생성물이며, 시트·공간·주요 행동·시간 순서를 검수하고 덕트 접합 및 문 지지 자세를 수정했습니다.

검증: 원본 파일 대조, 128개 원문 블록 보존, 9구간×9씬, ID·목차·이미지·manifest 검증, JavaScript 구문, 배포 SHA와 공개 HTTP 응답. 사용 가능한 브라우저 자동화 연결이 없어 실제 브라우저 화면·기기 설치 검증은 수행하지 못했습니다.
